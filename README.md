# Happy Birthday Vaishnavi 💕

A cute, scroll-based birthday gift site built with React, Vite, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Personalize

Search the project for `TODO:` — names, dates, photos, wishes, and letter text are marked there.

- **`src/constants/content.js`** — shared copy and password (`hbdvaish`)
- **`src/sections/LetterSection.jsx`** — full letter body
- Replace gradient blocks with `<img src="/photos/your.jpg" alt="..." className="..." />`

## Build for deploy

```bash
npm run build
npm run preview
```

Deploy the `dist` folder to Netlify, Vercel, GitHub Pages, etc.
